# Kritická revize auditu a implementace

Datum: 2026-11-14.
Podklady: syntéza `2026-11-14-synthesis.md`, aktuální změny v repozitáři a samostatné spuštění `go test ./...`.
Revize posuzuje dokumentaci a implementaci. Nejde o živý test instalace v klientovi.

## Závěr

Syntéza odpovídá zadání a správně rozlišuje přenosný skill od hostitelského hooku.
Zvolený rozsah je přiměřený: bez dalšího runtime, bez automatického uploadu a bez vlastního klasifikátoru témat.
Před dokončením opravte následující nesoulady. Jejich nalezení neznamená, že plugin již zveřejnil data nebo poškodil nastavení.

## Požadované opravy

- **P1 — aktivace mimo hostitele s hooky není součástí samotného instalačního skillu.**
  `docs/INSTALL.md` slibuje vložení odkazu na odpovědní skill a profil do trvalých instrukcí.
  `skills/ztc-install/SKILL.md` však pouze ukládá profil a odkazuje na návod.
  Doplňte explicitní krok aktivace pro hostitele bez hooků, zachování existujících instrukcí a ověření dostupnosti profilu.
  Bez podpory trvalých instrukcí musí instalace označit nastavení jako platné pouze pro relaci.

- **P2 — zdrojová specifikace stále odporuje opraveným pravidlům slovníku.**
  `spec/ztc-009.md`, sekce 10.4, vyžaduje schválenou náhradu a vylučuje nové slovo stejného významu.
  To neodpovídá odkazům `@X.Y` ani zkratkám vedle plných názvů.
  Doplňte povolený odkaz na existující pravidlo a úzkou výjimku pro technickou zkratku.
  Odpovídající pokyny musí mít také LLM profil.

- **P2 — šablona PR předpokládá předchozí issue.**
  `.github/PULL_REQUEST_TEMPLATE.md` obsahuje neoznačené „Souvisí s issue: #“.
  Označte issue jako volitelné, aby nový dávkový příspěvek neměl protichůdné pokyny.

- **P2 — rozsah podpory Codexu není v návodu dostatečně přesný.**
  Syntéza uvádí omezení dokumentované podpory pluginových hooků na ruční instalaci v Codex desktop.
  Instalační návod musí toto omezení a neověřenou živou aktivaci zachovat.
  Kompatibilní manifest nepovažujte za důkaz podpory ve všech verzích CLI ani veřejném katalogu.

## Co obstálo při revizi

- Rozhodnutí o tématu a trivialitě předchází načtení přísného LLM profilu.
- Výslovná žádost o ZTČ obejde výchozí triviální výjimku; vypnutí a výjimky profilu mají popsané pořadí.
- Instrukce oddělují místní použití od souhlasu s konkrétním veřejným příspěvkem.
- Ověření connectoru rozlišuje existenci, přihlášení a schopnost zapisovat; Git sám PR nevytváří.
- Chybějící nástroj ani odmítnutí příspěvku neblokují místní použití.
- CSV se čte jako data, nikoli jako instrukce pro agenta.
- Nové oborové CSV se automaticky validuje; základní slovník zůstává povinný.
- Kontrola existence pravidla používá stávající mapu počtů; nevytváří konkurenční seznam.
- Testy skutečně spouštějí hook, včetně cesty s mezerami a vstupu obsahujícího příkaz.

## Meze důkazů

`go test ./...` při této revizi prošlo včetně balíčku `plugincheck`.
To dokládá testované parsování, validaci a běh shellového hooku, nikoli věrné chování jazykového modelu.
Test hooku porovnává soubory v testovacím adresáři; obecný zákaz zápisu nebo sítě není vynucován sandboxem testu.
Statická kontrola jednoduchého skriptu nezjistila zápisy ani síťové příkazy.

Neověřeno: živá instalace Claude Code a Codex, další relace, Windows bez POSIX shellu a skutečná publikace PR.
Téma a trivialitu posuzuje agent; tvrzení o zaručených ZTČ odpovědích ve všech prostředích by nebylo podložené.
Odborná správnost všech slovníkových definic zůstává mimo rozsah této revize.

## Vypořádání rodičovským agentem

Všechny čtyři nálezy byly opraveny po revizi:

- Instalační skill obsahuje aktivaci trvalého odkazu a ověření další relace, pokud je dostupné.
- Specifikace 10.4 a LLM profil popisují náhradu odkazem i výjimku pro technickou zkratku.
- Šablona PR označuje issue za volitelné.
- Návod vymezuje Codex desktop, ruční instalaci a neověřenou podporu pluginových hooks v CLI.

Nezávislá simulace navíc vedla k časné větvi pro uživatele, který odmítl veškeré příspěvky.
Takové nastavení přeskočí nabídku publikace i kontrolu GitHubu.
